# Roadmap

This roadmap is ordered by user value, not promised dates.

## M0 — Local workbench (current)

- [x] JSON/YAML parsing and conversion
- [x] Auto-detection, pretty output and compact JSON
- [x] Syntax errors and document statistics
- [x] Tree explorer and focused JSONPath query
- [x] Local import, clipboard and download
- [x] Responsive interface and core tests
- [ ] Keyboard command palette
- [ ] Persist optional preferences without persisting documents

## M1 — Schema intelligence

- [ ] JSON Schema draft 2020-12 validation
- [ ] Schema inference with confidence annotations
- [ ] Inline error paths and fix suggestions
- [ ] Schema-aware example generator
- [ ] Fixture suite for ecosystem edge cases

## M2 — Compare and transform

- [ ] Semantic JSON/YAML diff
- [ ] Patch generation and application
- [ ] Sort and filter operations with preview
- [ ] JSON Pointer and advanced JSONPath
- [ ] Reusable transformation recipes

## M3 — Large files and CLI

- [ ] Web Worker parser and cancellation
- [ ] Virtualized tree and editor rendering
- [ ] `@structura/core` package
- [ ] `structura` CLI for stdin/stdout pipelines
- [ ] Machine-readable diagnostics and exit codes

## M4 — Format ecosystem

- [ ] TOML adapter
- [ ] XML adapter with explicit loss warnings
- [ ] CSV shape explorer
- [ ] Plugin conformance kit
- [ ] Editor extensions built on the core package
